# Fiche appareil : iPad d'Elias

| | |
|---|---|
| Modèle | iPad Pro 11" **1re génération (2018)**, identifiant `iPad8,3` |
| Puce | Apple A12X |
| RAM | **4 Go** |
| Stockage | 512 Go (environ 419 Go libres) |
| iPadOS | 26.5 |
| Émulateur installé | Fin 3.4.0 |

## Ce qu'on peut attendre

D'après la détection de Fin sur cet iPad :
- GB, GBC et GBA : tournent bien.
- DS et DSi : les titres légers.
- GameCube, Wii et Triforce : **non recommandés**.
- Wii U et 3DS : marqués « Premium ». Cette mention semble désigner l'**offre payante**, pas une note de performance.

La Wii U est **plus gourmande que la Wii**. Si Fin déconseille déjà la Wii sur cet
iPad, il faut s'attendre à ce que la plupart des jeux Wii U 3D soient injouables
(trop lents, ou plantages faute de RAM). Les 4 Go de RAM sont le principal frein :
c'est aussi pour ça que MeloCafe et MuffinEMU, qui demandent beaucoup de
mémoire, ne sont pas conseillés ici.

## Conseils

1. **N'achetez pas l'offre Premium à l'aveugle.** Regardez d'abord s'il y a un
   essai gratuit. Sinon, un achat sur l'App Store peut être remboursé via
   reportaproblem.apple.com.
2. Pour tester, prenez d'abord un jeu **léger, en 2D**.
3. Réglages : résolution 1x, shaders asynchrones activés, iPad branché, coque
   retirée (l'appareil chauffe).
4. Fermez toutes les autres apps avant de lancer un jeu.
5. Pour vraiment jouer à la Wii U, il faut un iPad avec 8 Go de RAM minimum :
   iPad Pro M1 ou plus récent, ou iPad Air M2 ou plus récent.
